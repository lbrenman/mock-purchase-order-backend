Supplier order collaboration

Every request this page sends, newest first. Select a row for headers, body and a cURL command. Keys are masked on screen.

Connection

The base address is everything before /purchase-orders, for example your façade URL ending in /supplier-collaboration/v1.

Consumers

Add one consumer per API key, for example each supplier and an internal procurement app. Switch between them at the top of the page to see what each one is allowed to see.

Settings, including API keys, are saved in this browser only. Exported files contain the keys in plain text.
